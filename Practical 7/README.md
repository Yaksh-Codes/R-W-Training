# 📊 Sales Data Analyzer & Visualization

A Python-based **Sales Data Analysis and Visualization** project developed using **Object-Oriented Programming (OOP)**. This application provides a menu-driven interface to load, explore, manipulate, analyze, and visualize sales data from CSV files.

The project uses **Pandas, NumPy, Matplotlib, and Seaborn** to perform data analysis and create meaningful visualizations.

---

## 🚀 Features

### 📂 1. Load Dataset
- Load sales data from CSV files.
- Handles file-related errors.
- Displays dataset shape after successful loading.

### 🔍 2. Explore Data
- Display first 5 rows.
- Display last 5 rows.
- View column names.
- Check data types.
- Display dataset information.
- Check dataset shape.

### 🔄 3. DataFrame Operations
- Add new columns.
- Perform mathematical operations.
- Combine DataFrames.
- Split DataFrames based on criteria.
- Sort DataFrames.
- Filter specific records.

### 🧹 4. Handle Missing Data
- Identify missing values.
- Fill missing numeric values using the mean.
- Drop rows containing missing values.
- Replace missing values with custom values.

### 📈 5. Descriptive Statistics
Generate important statistical insights such as:

- Sum
- Mean
- Median
- Standard Deviation
- Variance
- Minimum
- Maximum
- Quartiles

### 📊 6. Data Visualization

The project supports multiple visualization types:

- Bar Chart
- Line Chart
- Scatter Plot
- Histogram
- Box Plot
- Correlation Heatmap
- Subplots

### 💾 7. Save Visualization
Save generated visualizations in:

- PNG
- JPG
- JPEG

### ⚡ 8. Advanced Operations
- Create Pivot Tables.
- Re-index datasets.
- Perform GroupBy operations.
- Apply aggregations such as:
  - Sum
  - Mean
  - Minimum
  - Maximum
  - Count
