# 📖 Personal Journal Manager

A simple and user-friendly **Personal Journal Manager** built with **Python**. This console-based application allows users to create, view, search, and delete journal entries while demonstrating core Python concepts such as file handling, functions, loops, conditionals, and exception handling.

---

## 📌 Project Overview

The Personal Journal Manager is a menu-driven application that helps users maintain a digital journal. Each journal entry is automatically saved with a timestamp, making it easy to keep track of daily thoughts and activities. The application stores all journal entries in a text file (`journal.txt`) and provides an intuitive console interface for managing them.

This project is ideal for beginners learning Python and file handling concepts.

---

## ✨ Features

- 📝 Add new journal entries
- 📖 View all saved journal entries
- 🔍 Search journal entries by keyword or date
- 🗑️ Delete all journal entries with confirmation
- 📅 Automatic date and time stamp for every entry
- 💾 Persistent storage using a text file
- ⚠️ Exception handling for missing files
- ✅ User-friendly menu-driven interface

## ⚙️ Program Functionalities

### ➤ Add a New Entry
- Accepts journal input from the user.
- Automatically records the current date and time.
- Saves the entry in `journal.txt`.

### ➤ View All Entries
- Displays all saved journal entries.
- Shows a message if no entries exist.
- Handles missing file exceptions.

### ➤ Search for an Entry
- Searches journal entries using a keyword or date.
- Displays all matching entries.
- Informs the user if no matching records are found.

### ➤ Delete All Entries
- Requests confirmation before deletion.
- Removes all journal entries safely.
- Prevents accidental deletion.
