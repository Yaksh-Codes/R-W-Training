# Smart Event Management System

A professional **MySQL database project** designed to manage events, venues, organizers, attendees, ticket bookings, and payments. The project demonstrates practical SQL concepts including CRUD operations, filtering, aggregation, joins, subqueries, date/time functions, string functions, window functions, and `CASE` expressions.

## 📌 Project Overview

The Smart Event Management System provides a structured relational database for event organizers to manage the complete event lifecycle.

The system can be used to:

- Manage events and venues
- Manage organizers and attendees
- Track ticket bookings and booking status
- Track successful, failed, and pending payments
- Calculate event revenue
- Analyze ticket sales and attendance
- Identify high-demand and low-demand events
- Generate useful business reports

## 🎯 Objectives

## 📈 Key SQL Queries

### Top 5 Highest-Revenue Events

```sql
SELECT
    e.event_id,
    e.event_name,
    COALESCE(
        SUM(
            CASE
                WHEN p.payment_status = 'Success'
                THEN p.amount
                ELSE 0
            END
        ), 0
    ) AS total_revenue
FROM Events e
LEFT JOIN Tickets t
    ON e.event_id = t.event_id
LEFT JOIN Payments p
    ON t.ticket_id = p.ticket_id
GROUP BY e.event_id, e.event_name
ORDER BY total_revenue DESC
LIMIT 5;
```

### Event Demand Classification

```sql
SELECT
    event_id,
    event_name,
    total_seats,
    available_seats,

    ROUND(
        available_seats * 100.0 / total_seats,
        2
    ) AS available_percentage,

    CASE
        WHEN available_seats < total_seats * 0.20
            THEN 'High Demand'

        WHEN available_seats BETWEEN
             total_seats * 0.20
             AND total_seats * 0.50
            THEN 'Moderate Demand'

        ELSE 'Low Demand'
    END AS demand_category

FROM Events
ORDER BY available_percentage ASC;
```

### Payment Categorization

```sql
SELECT
    payment_id,
    ticket_id,
    amount,
    payment_status,

    CASE
        WHEN payment_status = 'Success'
            THEN 'Successful'

        WHEN payment_status = 'Failed'
            THEN 'Failed'

        ELSE 'Pending'
    END AS payment_category

FROM Payments;
```

### Event Revenue Ranking

```sql
WITH EventRevenue AS
(
    SELECT
        e.event_id,
        e.event_name,
        COALESCE(
            SUM(
                CASE
                    WHEN p.payment_status = 'Success'
                    THEN p.amount
                    ELSE 0
                END
            ), 0
        ) AS total_revenue
    FROM Events e
    LEFT JOIN Tickets t
        ON e.event_id = t.event_id
    LEFT JOIN Payments p
        ON t.ticket_id = p.ticket_id
    GROUP BY e.event_id, e.event_name
)

SELECT
    event_id,
    event_name,
    total_revenue,
    RANK() OVER (
        ORDER BY total_revenue DESC
    ) AS revenue_rank
FROM EventRevenue
ORDER BY revenue_rank;
```
